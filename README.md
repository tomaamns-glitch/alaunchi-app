# ALaunchi

**English** · [Español](#español)

ALaunchi is a free, non-commercial Minecraft: Java Edition launcher for Windows, built for a small private group of friends. It installs and keeps up to date the modpacks we play together, handles Java and mod loaders (Forge, NeoForge, Fabric) automatically, and adds the social features we use every day: friends, chat and shared online instances protected by access codes.

- Website and download: https://alaunchi.github.io
- Privacy policy: https://alaunchi.github.io/privacy.html
- Terms of use: https://alaunchi.github.io/terms.html
- Contact: alaunchi.support@gmail.com

### Third-party content

Mods, shaders and resource packs from other creators are always downloaded from their original source (currently Modrinth) and checked by hash. ALaunchi never re-hosts third-party files: modpacks and anything shared between players only reference the original project and file.

### Development

Electron + React + TypeScript, with Firebase for the online features.

```bash
npm install
npm run electron:dev   # Vite + Electron with hot reload
npm run typecheck
```
